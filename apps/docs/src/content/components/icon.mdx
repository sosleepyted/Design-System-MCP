Icons are plain inline SVGs vendored from Material Symbols (Outlined). They carry
no runtime dependency, render on the server in any host, and inherit colour from
the surrounding text via `currentColor`, so they stay on the token system.

## Set

The starter set. Add an icon by dropping its outlined path into the registry.

</Demo>

## Sizes

`size` sets width and height in pixels (default 20). Pair the icon size with the
text it sits beside.

</Demo>

## Colour

Icons use `fill: currentColor`, so they take the colour of their text context.
Apply a token colour with a class on the icon or its parent.

<Demo title="Colour">
  <IconColor client:visible />
</Demo>

## Accessibility

- Icons are **decorative by default** (`aria-hidden`), so they are skipped by
  screen readers. This is correct when the icon sits next to a text label.
- When an icon stands alone and carries meaning, pass `title` to expose it as a
  labelled image (`role="img"` with an accessible name).
- Never rely on colour alone to convey state; pair a status icon with text.

## Content

- Use the Material Symbols name as-is (`arrow_forward`, `check_circle`).
- Choose the icon that names the action, not a decorative stand-in.
