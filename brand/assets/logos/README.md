# Logo files

No official kit files live in this folder yet, deliberately. Decision of
2026-07-06: kit files enter the repo only when the brand owner gives an
explicit go. Until then, the single source for logo files is the branding
elements folder on Google Drive (UCM account required):

https://drive.google.com/drive/folders/1I6p89HNb2kteBE6LIKWr4fAlxixvjdFb

## production/

The `production/` subfolder holds records, not kit files: the logo assets
the live www.ucm.jobs site actually serves (downloaded from its public
CDN, 2026-07-07) plus a screenshot of the live header pill. They exist so
the logo page can show each logo next to its use case. They are evidence
of the current production state, including its known divergences from the
rules (dotless icons, retired Pine color); never treat them as sanctioned
artwork. See guidelines/logo.md and the tracker audit.

## The rule, wherever the files come from

- The logo is always "ucm." in lowercase, closed by the accent dot in
  #FF9932. Never "UCM", never "Ucm", never without the dot.
- The wordmark is set in Nunito Extra-Bold 800. Nunito is used for nothing
  else.
- Never retype or rebuild the logo. Use the delivered files only.
- The lowercase form belongs to the logo alone; in running text the name is
  written UCM.

Full logo guidance: ../../guidelines/logo.md.
